## 🚀 Quick Start Guide

### Prerequisites
- Node.js 18+ (for browser automation and media pipeline)
- Python 3.10+ (for code tools and local LLM)
- ADB (optional, for Android control)
- Ollama (optional, for local LLM)

### Installation

```bash
# Clone the repository
git clone https://github.com/CyberPrince-Alien/Shopno-AI.git

# Navigate to the project
cd Shopno-AI

# Install dependencies
npm install

# Launch Shopno AI
npm start
```

### One-Line Magic 🪄

```bash
# Ask Shopno AI to do ANYTHING in natural language:
"Create a video about AI from this script and post it to YouTube"
"Login to my Facebook and post about my new product"
"Analyze my codebase and find all security vulnerabilities"
"Tell me if my business idea is going to fail"
"Control my Android phone and take a screenshot"
```

That's it. No complex setup. No 50-step tutorial. Just **talk to it**.

## 🔧 Configuration

### Environment Variables
```env
# Optional: For cloud providers
OPENAI_API_KEY=your_key
HUGGINGFACE_API_KEY=your_key
POLLINATIONS_API_KEY=your_key

# Optional: For integrations
GITHUB_TOKEN=your_token
DISCORD_TOKEN=your_token
TELEGRAM_BOT_TOKEN=your_token
```

### Local LLM Setup (No API Keys Needed!)
```bash
# Install Ollama
curl -fsSL https://ollama.com/install.sh | sh

# Pull a model
ollama pull llama3.2

# Tell Shopno AI to use local LLM
"Use local LLM for all tasks"
```
